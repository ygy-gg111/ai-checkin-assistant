## 二、今日重点问题与处理记录

### 1. 首页统计与用户设置统计不一致

**现象**：同一个“本月 AI 使用统计”，首页和用户设置页显示不一样。  
**原因**：两边原先不是用同一套计算来源，有的读首页汇总，有的读设置页本地计算。  
**处理**：抽出统一统计逻辑，首页、用户设置、后续可复用模块统一共用。  
**结果**：统计口径一致，刷新后已对齐。

### 2. Next 本地开发服务出现旧缓存影响

**现象**：页面数据或接口表现与代码实际状态不一致，用户刷新后仍看到旧结果。  
**原因**：本地已有旧的 `next dev` 进程和缓存输出，导致页面和 API 路由没有及时反映新代码。  
**处理**：

- 停止旧进程
- 清理 `.next`
- 重启开发服务

**结果**：页面恢复为最新联调状态，首页和用户设置统计也恢复一致。

### 3. 创建页布局在 9 张图场景下反复超高

**现象**：新增 Prompt 选择后，创建页在上传 9 张图时容易把底部区域顶出去。  
**原因**：左侧表单高度被图片缩略图区、Prompt 区和文本输入区叠加撑高。  
**处理过程**：

- 压缩过间距与缩略图尺寸
- 试过 9 张图单行等分
- 试过更紧凑的 Prompt 预览
- 最后改成横向缩略图带 + 紧凑 Prompt 摘要

**结果**：页面高度控制比之前更稳定，同时尽量避免把图片压缩得太难看。

### 4. Prompt 选择存在“选了但没生效”的断链问题

**现象**：用户在 Prompt 相关区域选中模板，但最终 AI 生成文案没有使用该模板。  
**原因**：后端支持 `promptTemplateId`，但前端创建页之前没有真正传递这个值。  
**处理**：

- 创建页新增模板拉取与选择
- 生成请求携带 `promptTemplateId`
- 后端校验并读取对应模板内容

**结果**：Prompt 选择已经可以真实参与生成，不再只是展示用途。
