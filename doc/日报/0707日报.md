## 🌟 一、今日核心工作成果

### 1. 业务 Mock 数据替换为 Prisma 真实查询

* **历史/文章列表真实化**：`/api/posts` 与 `/api/history` 改为按当前登录用户查询 Prisma `Post` 数据，支持分页、主题、风格和关键词筛选。
* **打卡详情真实化**：`/api/posts/[id]` 改为按 `id + userId` 查询真实记录，并带出图片列表；删除接口改为软删除 `status = DELETED`。
* **统一输出结构**：新增 `src/lib/posts/format.ts`，集中处理列表、详情、标签、封面图、日期时间等字段转换，避免接口重复拼装。

### 2. 打卡日历接入真实数据

* **月视图聚合**：`/api/calendar` 按月份查询当前用户打卡记录，并按 `checkinDate` 聚合每日打卡次数与主题。
* **单日明细**：`/api/calendar/day` 按日期返回当天真实打卡列表。
* **前端联动**：日历页移除大段本地 Mock 数据，改为随月份切换请求真实 API；右侧详情随选中日期请求当天记录。

### 3. Prompt 模板接口接入数据库

* **模板列表**：`/api/prompts` 改为查询 `PromptTemplate` 表，支持按 `scene` 筛选启用模板。
* **模板更新**：`/api/prompts/[id]` 支持真实更新 `name`、`content` 和 `isActive`，并处理模板不存在、空内容等校验错误。

### 4. 本地图片上传真实落地

* **真实写盘**：`/api/upload` 改为校验并保存图片到 `UPLOAD_DIR`，支持 JPG、PNG、WebP，限制单张最大 10MB、最多 9 张。
* **元数据返回**：上传结果返回真实 URL、文件名、大小、MIME 类型和可解析的图片宽高。
* **本地访问路由**：新增 `/uploads/[...path]` 只读路由，用于本地开发环境按 `/uploads/yyyy/mm/file` 访问已上传图片。
* **创建页联动**：创建打卡页改为选择图片后调用 `/api/upload`，缩略图使用上传后的真实 URL。

### 5. OpenAI Provider 与生成落库主链路

* **Provider 实现**：新增 `src/lib/ai/openai.ts`，通过原生 `fetch` 调用 OpenAI Chat Completions，并要求模型返回 JSON。
* **统一 AI 输出**：Provider 返回 `analysis`、`title`、`content`、`tags`、`coverText` 和 token usage。
* **生成接口落库**：`/api/posts/generate` 改为查找 Prompt 模板、调用 AI Provider、创建 `Post`、批量关联 `PostImage`，并写入 `AIUsageLog`。
* **前端生成联动**：创建页点击生成时调用真实 `/api/posts/generate`，成功后展示接口返回结果；失败时展示统一错误提示。

### 6. 登录失败限流

* **IP + 邮箱维度限流**：新增 `src/lib/auth/rate-limit.ts`，按 IP 与邮箱组合记录登录失败次数。
* **失败累计、成功清理**：邮箱不存在或密码错误都会累计失败次数；登录成功后清理该组合的失败记录。
* **统一错误语义**：超过阈值后返回 `429 TOO_MANY_REQUESTS`，普通失败仍保持“邮箱或密码错误”，避免暴露账号是否存在。

## 🛠️ 二、排查与注意事项

### 1. React Hook 顺序问题

日历页接入真实 API 时，曾把 `useMemo` 放在未登录 early return 之后，触发 ESLint 的 Hook 顺序错误。已改为普通派生值，并移除旧 Mock 辅助函数，保证 Hook 调用顺序稳定。

### 2. 上传文件访问与 Turbopack 构建提示

为兼容 `UPLOAD_DIR="./uploads"` 与浏览器 `/uploads/...` URL，新增了本地只读文件路由。`next build` 可以通过，但 Turbopack 仍提示一次 NFT 文件追踪 warning，来源是该路由需要 `fs.readFile` 读取本地上传文件；当前不阻断构建。

### 3. OpenAI Key 运行时要求

真实生成链路依赖 `.env` 中的 `OPENAI_API_KEY`。未配置时不会返回假数据，而是统一返回 `AI_SERVICE_ERROR`，避免误以为已经真实生成成功。
