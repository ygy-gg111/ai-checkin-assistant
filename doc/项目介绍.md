# 项目介绍（Project Introduction）

## 项目名称

**AI Check-in Assistant（AI 打卡日志助手）**

------

# 一、项目背景

随着 AI 大模型的发展，越来越多的人开始通过社交平台记录自己的生活，例如：

- 坚持游泳
- 坚持跑步
- 健身打卡
- 阅读打卡
- 学习记录
- 编程成长
- 减肥计划
- 旅行记录

然而，坚持记录最大的困难并不是拍照，而是**不知道写什么**。

很多人在拍完照片之后，需要花费大量时间思考：

- 今天应该怎么写？
- 标题怎么起？
- 怎么写得真实一点？
- 怎么写不会太鸡汤？
- 标签怎么写？
- 小红书喜欢什么风格？

最终导致很多人因为写文案太麻烦而放弃记录。

因此，希望开发一款 **AI 打卡日志助手**，帮助用户快速完成从图片到文案的整个创作流程。

------

# 二、项目目标

本项目旨在打造一款面向普通用户的 **AI 内容创作工具**。

用户只需要上传当天的照片，并补充几句简单描述，AI 即可自动完成图片分析，并生成适合社交平台发布的内容。

整个流程控制在 **30 秒以内**。

核心目标包括：

- 降低坚持记录的门槛
- 提高内容创作效率
- 保持账号内容风格统一
- 帮助用户养成持续记录的习惯

------

# 三、产品定位

AI Check-in Assistant 并不是传统意义上的 AI 写作工具。

它更加专注于 **生活记录场景**。

用户每天只需要完成两件事情：

1. 上传当天照片
2. 输入一句简单描述

剩余工作全部交给 AI 完成。

例如：

用户输入：

> 今天练蛙泳，腿还是不怎么走水。

上传：

- 游泳自拍
- 泳池照片

系统即可自动生成：

- 小红书标题
- 正文
- 标签
- 封面标题建议
- 发布时间建议

整个过程无需人工编写文案。

------

例如：

### 普通生活记录用户

------

# 五、核心价值

本项目的核心价值并不是帮助用户"写文案"。

真正的价值在于：

> **帮助用户持续记录，而不是持续思考。**

用户只需要专注于：

- 今天做了什么
- 今天拍了什么

AI 负责：

- 图片理解
- 内容组织
- 文案表达
- 标签推荐
- 风格统一

真正做到：

> **记录生活，而不是为了发内容而发内容。**
>
> 



# 六、MVP（第一阶段）

第一阶段仅聚焦于一个核心场景：

> **上传图片 → AI 分析 → 生成小红书文案**

主要功能包括：

- 上传图片
- 输入当天记录
- AI 分析图片内容
- AI 生成标题
- AI 生成正文
- AI 推荐标签
- 一键复制内容

第一阶段不考虑：

- 视频分析
- 自动发布
- 数据分析
- 评论生成
- 多平台同步

优先完成最核心的使用流程。

------

# 七、技术方案

项目采用现代 Web 全栈开发方式。

前端与后端统一使用 Next.js。

AI 能力通过云端大模型 API 提供。

当前阶段采用 API 调用模式，后续支持本地模型部署。

技术栈如下：

- Next.js
- TypeScript
- Prisma
- MySQL
- Tailwind CSS
- OpenAI API（默认）
- AI Provider（统一模型管理）

整个项目保持单体应用（Monolith）架构，降低开发和维护成本。

------

# 八、产品特点

相比传统 AI 写作工具，本项目具有以下特点：

## 图片驱动

以图片为核心，而不是文字。

AI 会先理解图片，再结合用户输入生成文案。

------

## 固定创作流程

所有内容均按照统一流程生成：

图片 → 分析 → Prompt → 文案 → 标签

保证输出质量稳定。

------

## 人设一致性

支持预设账号定位，例如：

> 一个普通程序员的生活重启记录。

生成的内容始终围绕统一的人设和表达风格，避免账号内容割裂。

------

## Prompt 可配置

Prompt 独立管理，不写死在代码中。

后续可根据不同平台或不同账号风格进行调整，而无需修改业务逻辑。

------

## AI Provider 可扩展

当前默认接入 OpenAI API。

未来可无缝切换至：

- Gemini
- Qwen
- Claude
- 本地模型（Qwen-VL、InternVL 等）

业务代码无需修改。

------

## 核心功能

AI Check-in Assistant 不仅是一款 AI 文案生成工具，更是一款帮助用户持续记录和回顾成长过程的打卡平台。

产品围绕「记录、生成、回顾、坚持」四个核心环节展开，形成完整的打卡闭环。

### 1. AI 智能内容生成

用户上传当天照片，并输入简单描述。

系统自动完成：

- 图片内容分析
- 场景识别
- 文案生成
- 标题生成
- 标签推荐
- 封面标题建议

整个过程无需用户编写完整文案，生成结果可直接复制发布到小红书。

------

### 2. 打卡历史管理

系统自动保存每一次生成的内容。

用户可以随时查看：

- 原始图片
- 用户输入
- AI 分析结果
- AI 生成文案
- 标签
- 创建时间

同时支持重新生成、复制和删除历史记录。

------

### 3. 打卡日历

系统提供月历视图，帮助用户更加直观地查看自己的坚持过程。

日历会自动标记每天的打卡状态。

用户可以快速查看：

- 哪些日期已经完成打卡
- 哪些日期尚未打卡
- 每天生成了多少条内容
- 当前连续打卡天数（后续版本）

点击任意已打卡日期，可查看当天所有打卡内容，并进入对应详情页面重新查看、复制或重新生成文案。

打卡日历不仅是历史记录入口，也是整个产品中最重要的成长记录模块，让用户能够清晰地看到自己的坚持轨迹。

------

### 4. Prompt 模板管理

系统内置多种内容模板。

例如：

- 游泳打卡
- 跑步打卡
- 学习记录
- 日常生活

不同模板拥有不同的 Prompt 配置。

用户可根据不同场景快速切换生成风格，同时保证账号整体内容保持统一的人设和表达方式。

------

### 5. AI Provider 可扩展

当前版本默认使用 OpenAI GPT-4o mini。

后续可无缝切换：

- Gemini
- Claude
- Qwen
- 本地模型

业务层无需修改即可完成模型切换，为产品未来扩展预留充足空间。
