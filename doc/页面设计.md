1. PC 端页面设计 Prompt 修正版

   ## 通用设计要求

   请为 AI Check-in Assistant 生成 **PC 端 Web 管理后台风格** 的 HTML + SVG 静态页面。

   产品定位：

   AI 打卡日志助手，用户上传图片和文字，AI 自动生成小红书打卡文案，并通过日历查看坚持记录。

   设计风格：

   - PC 端优先
   - SaaS Dashboard
   - AI 工具平台
   - Linear 风格
   - Notion 风格
   - Raycast 风格
   - Cursor / Claude / ChatGPT 工具感
   - 干净、克制、高级
   - 大面积留白
   - 左侧导航栏
   - 顶部操作栏
   - 卡片式内容区

   画布尺寸：

   ```text
   1440px × 1024px
   ```

   布局结构：

   ```text
   左侧 Sidebar：240px
   顶部 Header：72px
   主内容区 Main：剩余宽度
   右侧可选 Panel：320px
   ```

   视觉规范：

   ```text
   Background: #F8FAFC
   Sidebar: #FFFFFF
   Card: #FFFFFF
   Primary: #2563EB
   Success: #10B981
   Warning: #F59E0B
   Text: #111827
   SubText: #6B7280
   Border: #E5E7EB
   Radius: 16px
   Shadow: soft
   Grid: 8px
   Font: Inter / system-ui / PingFang SC
   ```

   输出要求：

   1. 生成完整 HTML 文件。
   2. 使用内联 CSS。
   3. 使用 SVG 图标。
   4. 不依赖外部 UI 库。
   5. 不使用 Tailwind。
   6. 页面必须是 PC 端布局。
   7. 不要生成移动端底部导航。
   8. 使用左侧导航 + 顶部 Header。
   9. 每个页面单独生成 HTML。
   10. 所有页面风格统一，方便后续转成 Next.js 组件。
