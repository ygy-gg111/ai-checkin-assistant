## 二、任务安排

### 1. Prompt 设置页完整联调

- 将 Prompt 设置页从静态配置切换为真实接口数据。
- 接入 `/api/prompts`，完成模板列表真实加载。

- 补齐新增 Prompt 模板能力。

- 校验主题、风格、模板状态与创建页选择逻辑保持一致。
- 验证创建页选择新建或编辑后的 Prompt 后，AI 生成结果能够真实使用对应模板。

### 2. 核心业务链路端到端验收

- 注册 / 登录后完整测试创建打卡流程。
- 验证图片上传、AI 生成、保存历史、历史详情、删除记录等流程。
- 验证日历页按真实打卡记录展示统计。
- 验证首页统计、用户设置统计、侧边栏摘要三处数据口径一致。
- 对未登录状态、空数据状态、接口失败状态做基础回归。

### 3. 创建页体验小范围稳定

- 继续观察 9 张图片上传场景下的布局高度。
- 微调图片缩略图带、Prompt 摘要区、左右栏视觉平衡。
- 避免新增功能继续挤压创建页主操作区。
- 保持改动小而集中，不做大范围视觉重构。

### 4. 清理现有 warning

- 优先处理当前已知 warning：
  - `src/app/api/posts/[id]/regenerate/route.ts`
  - `src/components/prompts/prompt-editor.tsx`
- 目标是让后续 `lint` 输出更干净，方便识别新问题。
- 如 warning 涉及较大重构，先做最小可行清理，避免影响主线联调。

### 5. 质量检查与日报沉淀

- 执行质量检查：
  - `npm run typecheck`
  - `npm run lint`
  - `npm run build`
- 如涉及 Prisma 或数据库结构变更，补充执行：
  - `prisma format`
  - `prisma validate`
  - `prisma generate`
- 将今日完成内容、问题处理、验证结果补充到 `0708日报.md`。
