## 一、今日核心目标

今日主线聚焦 **真实业务数据闭环**：

从登录用户身份出发，逐步打通“创建打卡、上传图片、AI 生成、保存历史、日历展示”的核心路径，优先减少 Mock 数据依赖。

## 二、任务安排

### 1. 业务 Mock 数据替换

- 将 `/api/posts`、`/api/history` 改为按当前登录用户查询真实 Prisma 数据。
- 将 `/api/calendar`、`/api/calendar/day` 接入真实打卡记录统计。
- 将 Prompt 相关接口逐步从 Mock 数据切换为数据库模板数据。

### 2. 真实上传落地

- 实现 `/api/upload` 的多图保存逻辑。
- 增加文件类型、文件大小、上传数量校验。
- 返回真实图片 URL、文件名、文件大小等元数据，供创建打卡页使用。

### 3. AI Provider 生成主链路

- 完成 `src/lib/ai/provider.ts` 的真实模型调用封装。
- 打通 `/api/posts/generate`：根据用户输入生成小红书标题、正文、封面语、标签等结构化结果。
- 将 AI 调用异常统一映射为 `AI_SERVICE_ERROR`。

### 4. 登录安全限流

- 对 `/api/auth/login` 增加 IP + 邮箱维度失败次数限制。
- 达到阈值后返回 `429 TOO_MANY_REQUESTS`。
- 保持登录失败文案统一，避免暴露账号是否存在。

### 5. 联调与验收

- 注册/登录后完整测试：创建打卡 -> 上传图片 -> AI 生成 -> 保存历史 -> 日历展示。
- 执行质量检查：
  - `npm run typecheck`
  - `npm run lint`
  - `npm run build`
- 将今日完成内容补进 `0707日报.md`。

5. **优先级 P2**：完整联调、构建验收和日报记录。
